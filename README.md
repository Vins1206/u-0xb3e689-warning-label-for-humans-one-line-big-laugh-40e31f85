# Warning Label for Humans: One Line, Big Laugh

A [make.fun](https://make.fun/c/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) bounty entry: the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer.

## The label

> WARNING: This human says 'I'm fine' while visibly on fire, then Googles its symptoms at 3 a.m. Do not feed after midnight.

122 characters, one line. The joke is recognition: the universal human habit of insisting everything is fine while quietly panicking, then self-diagnosing at 3 a.m. The laugh lands in the last few words, in pure printed-label voice ("Do not feed after midnight").

## How to run

```sh
python3 main.py   # writes the label to /output/entry.txt
```

Pure Python standard library, deterministic: two runs produce byte-identical output.

## Rubric self-score (judge criteria, most important first)

1. **On-subject, funny warning label for humans** — yes, a `WARNING:` label for every human. Strong.
2. **Laugh lands in one read, turn in the last few words** — "Do not feed after midnight" is the turn. Strong.
3. **Recognition, true about people** — "I'm fine" + 3 a.m. symptom-Googling is near-universal human behaviour. Strong.
4. **Sounds like a real printed label** — `WARNING:` / `Do not feed…` rhythm imitates the form. Strong.
5. **Inside 160 chars, whole line, one idea** — 122 chars, single idea (denial about health), no filler. Strong.

Candidates considered (6 drafted, scored against the rubric; this one won): the shared-braincell label, the 47-open-tabs label, the podcast/diet/feud label, the overheats-when-wrong label, and the five-more-minutes label — all valid, all weaker on the closing turn and recognition than the winner.
